## Resumo dos Conceitos Praticados

No freeCodeCamp, pratiquei a estrutura básica de uma página HTML: títulos, parágrafos, listas e a organização do conteúdo em forma de currículo. O lab de depuração foi a parte mais desafiadora, porque exigiu ler o código com atenção para achar erros de sintaxe (como tags mal fechadas ou atributos errados) em vez de escrever tudo do zero.

No Coddy, avancei pelas lições iniciais da trilha e cheguei ao módulo de condições, onde usei estruturas `if/else` para fazer o programa tomar decisões. A principal dificuldade foi o limite de energia da plataforma, que me impediu de continuar além das 7 lições. Ainda assim, as estruturas mais usadas foram as tags HTML básicas e as condicionais.
